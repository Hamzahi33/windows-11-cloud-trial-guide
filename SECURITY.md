# Security policy

This repository contains documentation and small administrative scripts. Do not publish passwords, cloud credentials, subscription IDs, tenant IDs, public IP addresses, or customer data in issues or pull requests.

If you find a security issue in a script, do not post exploit details publicly. Open a private security advisory for the repository maintainer or contact the maintainer through the GitHub profile.

The PowerShell baseline can change the local firewall and RDP access. Read the script first, run its default audit mode, provide a single trusted host address before applying changes, and keep provider-console recovery available. The scripts are provided without a guarantee of fitness for a particular environment.
