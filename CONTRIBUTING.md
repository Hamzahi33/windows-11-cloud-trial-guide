# Contributing

Thanks for helping keep this guide accurate and safe.

## Before opening a change

- Use official Microsoft or cloud-provider documentation for offer, licensing, support, and pricing claims.
- Include the date you checked a time-sensitive claim.
- Keep free-trial and student credits clearly separate from an always-free service.
- Do not submit instructions that evade account eligibility, quotas, software licensing, or provider abuse controls.
- Do not include credentials, access tokens, private IPs, account IDs, or personal billing details.

## Documentation changes

Keep the English and French guides aligned. When a provider changes an offer, update both the summary and `docs/research-sources.md`. Avoid exact price estimates unless they include region, VM size, date, and a link to the provider calculator.

## Scripts

Scripts must default to read-only behavior where practical, explain any state-changing action, and avoid embedding credentials. Infrastructure creation or deletion must never be described as free unless the provider confirms eligibility and limits for the exact configuration.
